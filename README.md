# Day 20 – Customer Order Analysis

## 📌 Overview

As part of my Data Analytics Internship at Veda Technology, I worked on Customer Order Analysis using the Sample Superstore dataset in Microsoft Excel.

The objective was to analyze customer ordering behavior and identify customers based on their order frequency.

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- Data Cleaning
- Data Analysis
- Data Visualization

## 📊 Dataset

Sample Superstore Dataset

## 🔍 Tasks Performed

- Created a unique Customer-Order Key
- Identified unique customer-order combinations
- Analyzed customer order counts using PivotTables
- Identified top customers based on order frequency
- Created a Top 10 Customer analysis
- Prepared customer segmentation based on order frequency

## 📈 Customer Segmentation

Customers were classified into three groups:

- **One-Time:** 1 order
- **Repeat:** 2–4 orders
- **Frequent:** 5+ orders

## 📊 Key Analysis

The analysis helped identify customers with higher order frequency and provided a basic understanding of customer purchasing behavior.

## 📁 Files Included

- Excel analysis workbook
- Customer order analysis
- PivotTable analysis
- Customer segmentation analysis
- Charts and visualizations

## 🎯 Conclusion

This task helped strengthen my practical understanding of customer-level data analysis, PivotTables, data cleaning, and visualization using Microsoft Excel.
